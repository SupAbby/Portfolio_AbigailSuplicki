FAHRENHEIT DASHBOARD

// ROLE UI/UX Designer
// DURATION 4 Weeks
// CLIENT School Project
// TOOLS Figma, Photoshop
SYS_ID: FAHRENHEIT_DASH DASHBOARD DESIGN
STATUS: COMPLETE OCTOBER 2026

// PROJECT OVERVIEW

The goal of this project was to create a desktop dashboard that would provide users with a clear and intuitive interface for managing their data or tasks. My interpretation of this project was related to my car. I am very passionate about my car and believed that a dashboard for my car would be a great way to showcase my skills in creative UI/UX design. I focused on a brutalism style using lots of detail, little open space, and one bold color to create a unique and visually striking dashboard design. I edited photos of my car to incorporate into the design in photoshop and created the prototype in Figma. I used many components to individually animate and create interaction in the design. The user is able to look at the weather, parts in the car, play music, put the car in park to stop the animations and more. This project allowed me to explore the intersection of automotive concept design and user experience, resulting in a functional and aesthetically pleasing dashboard solution.
