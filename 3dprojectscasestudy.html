STEAM ENGINE

During this project, I learned how to animate in Cinema 4D, hard surface modeling, and toon shading. During this project, the start of AI was being explored. We were asked to generate images of steam engines and create a unique design referencing those images. After creating this model. I was asked to push this design further and add in the steam. This pushed me to learn some simulation techniques in Cinema 4D.

STATUS: COMPLETE MAY 2024
SYS_ID: 3D_PROJECT_02 3D MODELING, SCULPTING, & TEXTURING

3D SNAKE ANIMATION

This project involved creating a textured 3D model using adobe substance painter and zbrush and placing this model into a 3D scene using cinema 4D. I focused on developing the textures on the snake to bring the character to life. I learned how to create a UV map, paint my own textures, and transfer the model between the different programs to create that final look. I sculpted the snake in a straight line and used a spline to align the snake in a curve and animate it in cinema 4D.

STATUS: COMPLETE MARCH 2026

SYS_ID: 3D_PROJECT_04 3D MODELING

PRODUCT ADVERTISMENT

This project was an introduction to a more realistic style of 3D modeling. We were prompted to pick an object, model it and create an advertisment for it. I chose to model my skateboard wheels. I learned how to study an object to model it and how to add pngs to the models like stickers. I used cinema 4D to model and texture the object, then illustrator to create the stickers and add in the text.

STATUS: COMPLETE MARCH 2024
SYS_ID: 3D_PROJECT_05 3D MODELING

LOW POLY ENVIRONMENT

This project was an introduction to creating low-polygon environments in 3D software. I learned how to optimize geometry for performance while maintaining visual quality. I also learned how to develop different lighting techniques and camera setups. The environment was built using Cinema 4D.
