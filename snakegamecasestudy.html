VIBE CODED SNAKE GAME

// ROLE UI/UX Designer
// DURATION 4 Weeks
// CLIENT School Project
// TOOLS Claude Code, Figma, ChatGPT
SYS_ID: SNAKE_GAME AI CODING
STATUS: COMPLETE OCTOBER 2026

// PROJECT OVERVIEW

This project was an exploration of using AI coding tools to create a simple yet engaging snake game. I utilized Claude Code, Figma, and ChatGPT to guide and refine the development process, learning valuable insights about integrating AI into creative workflows. During this project, I also learned how to implement a multiplayer feature, and build a game conroller using an arduino microcontroller. The final product is a playable snake game that demonstrates the potential of AI-assisted coding in game development. In my classes, we all used our controller and joined each game in a fun creative collison.
