TAMAGOTCHI

// ROLE UI/UX Designer
// DURATION 6 Weeks
// CLIENT School Project
// TOOLS Figma, Spline, After Effects
SYS_ID: TAMAGOTCHI GAME DESIGN
STATUS: COMPLETE MAY 2025

// PROJECT OVERVIEW

The goal of this project was to design a digital version of the classic Tamagotchi pet simulator, focusing on creating an engaging and intuitive user experience. I began by researching the original game's mechanics and aesthetics, then developed a modern UI/UX design that would appeal to new users. The design process involved creating 3D assets, prototypes, and compiling animations. I utilized Spline for 3D modeling and animation and After Effects for creating a finalized video. During this project, I learned how to use variables in Figma, a very valuble skill for creating interactive prototypes and design systems.
